# New launch!

On a random weekend, I decided to build a new website to host things I might write about in the future.

Personally, this was an exciting personal project to build. After working as a professional web developer for about two years now, I wanted a place where I could apply what I've learned and put some of those good practices into a hobby project of my own.

The first step was deciding on the tech stack. A few years ago, I probably would've challenged myself to build everything from scratch. These days, I've come to appreciate that not every project needs a reinvented wheel. Since the goal is simply to create a platform for writing, I went with
Eleventy, which is a simple JavaScript-based static site generator that takes Markdown files and renders them into a website. To make writing Markdown more seamless, I paired it with PageCMS.

One of the most fun parts of this project was experimenting with DeepSeek V4. It honestly exceeded my expectations and helped me put this website together in just a few hours. I also tried adding some agent-style context files and skills, which are techniques I've been using at work recently. Seeing how much those additions improved the quality of the output was surprisingly satisfying, and low-key made me feel a little ecstatic.

Overall, this site is a small project, but it feels like a nice milestone. I'll most possibly add more features, though I'll leave that out so as to avoid spoilers 😉
