# New launch!

On a random weekend, I decided to build a new website to host things I might write about in the future.

This website is powered by Eleventy, a static site generator. The fun part while developing this website is I've used and experimented with Deepseek V4. It honestly exceeded my expectations and helped me put this website together in just a few hours. I also tried adding some agent-style context files and skills, which are techniques I've been using at work recently. Seeing how much those additions improved the quality of the site's styling and structure was surprisingly satisfying. 

Overall, this site is a small project, but it feels like a nice milestone. As this is a personal site, I'm planning to add games into here which I might myself play it. If you're interested, they'll be appearing at a dedicated site tab once it's pushed live.
